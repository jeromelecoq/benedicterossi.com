# benedicterossi.com

Static portfolio site for Bénédicte Rossi, PhD — Scientific Illustrator.

## Hosting

Deployed on [Cloudflare Pages](https://pages.cloudflare.com/) with automatic deploys from this repo's `main` branch.

- **Live site:** https://benedicterossi.com
- **Build command:** none (pre-built static HTML)
- **Build output:** `/` (root)

## Structure

- `index.html` — Portfolio (covers, figures, logos, book illustrations)
- `About/index.html` — About & Contact page
- `css/` — Stylesheets (Bootstrap + custom)
- `js/` — jQuery, Bootstrap, site scripts
- `gallery/` + `gallery_gen/` — Portfolio images

## DNS

Domain registered at GoDaddy, nameservers pointed to Cloudflare. DNS managed in Cloudflare dashboard.
